# Noobietoria Studio

Chào mừng đến với trang tài liệu chính thức của **Noobietoria Studio**.

## Giới thiệu

Noobietoria Studio cung cấp một bộ API phong phú giúp bạn xây dựng trò chơi nhanh chóng và dễ dàng hơn — từ quản lý người chơi, vật phẩm, giao dịch, cho đến điều khiển môi trường và vật lý.

## Điều hướng nhanh

| Nhóm | Service |
|---|---|
| **Người chơi** | PlayerService, BanService, CameraService |
| **Vật phẩm & Kinh tế** | InventoryService, CurrencyService, PurchaseService, MarketplaceService, TradingService |
| **Giao diện** | UIService, NotificationService, ChatService |
| **Thế giới** | InstanceService, CollisionService, LightingService, PhysicsService, TweenService |
| **Gameplay** | QuestService, AchievementService, LeaderboardService, RewardService, CooldownService |
| **Xã hội** | PartyService, MatchmakingService, BadgeService, PassService |
| **NPC & AI** | PathfindingService, DialogueService, ProximityService, SpawnService |
| **Hệ thống** | DataStoreService, HttpService, AnalyticsService, LocalizationService, TeleportService |
| **Mạng & Script** | NetworkService (NetworkEvent, ServerScript, ClientScript, ModuleScript) |
| **Âm thanh & Hiệu ứng** | AudioCService, SoundEffectService, EffectService |
| **Thủ công** | CraftingService, MailService, InputService, AccessoryService |
